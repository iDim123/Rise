# Debug Commands

Открыть консоль: клавиша **`~`** (или **F2**). Ввести команду и нажать Enter.
Работает только в Studio (`RunService:IsStudio()`).

## Общие

| Команда              | Что делает                          |
|----------------------|-------------------------------------|
| `/help`              | Список всех доступных команд        |
| `/save`              | Принудительное сохранение            |
| `/data`              | Показать текущие данные в консоли    |
| `/addxp 500`         | Добавить 500 XP (по умолчанию 500)  |
| `/additem blood_essence` | Добавить предмет                |
| `/togglesave`        | Вкл/выкл автосохранение             |
| `/wipe`              | Удалить все сохранённые данные       |

## День / Ночь

| Команда              | Что делает                          |
|----------------------|-------------------------------------|
| `/settime 14`        | Перемотать время на 14:00            |
| `/settime 0`         | Перемотать на полночь                |
| `/timescale 50`      | Ускорить время в 50 раз             |
| `/timescale 1`       | Вернуть нормальную скорость          |
| `/phase`             | Показать текущую фазу и лунную фазу |

## Лунный цикл

| Команда              | Что делает                          |
|----------------------|-------------------------------------|
| `/lunar blood_moon`  | Переключить на кровавую луну         |
| `/lunar full_moon`   | Переключить на полнолуние            |
| `/lunar new_moon`    | Переключить на новолуние             |
| `/lunar waxing`      | Переключить на растущую луну         |
| `/lunar waning`      | Переключить на убывающую луну        |

## Баффы

| Команда              | Что делает                          |
|----------------------|-------------------------------------|
| `/buff sunlight_exposure 10` | Наложить бафф на 10 сек      |
| `/buff damage_boost 30`     | +30% урон на 30 сек           |
| `/clearbuffs`        | Снять все баффы с персонажа          |
