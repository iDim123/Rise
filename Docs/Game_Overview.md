# Rise — Game Overview

> Дизайн-документ игры. Описывает концепцию, геймплей, системы и целевой опыт.

---

## Концепция

**Rise** — кооперативная Action RPG с изометрической камерой на платформе Roblox. Вампирская тематика, вдохновлённая V Rising. Игроки — пробудившиеся вампиры, которые исследуют мир, сражаются с врагами, подчиняют слуг, осваивают школы магии и строят свой замок.

### Ключевые отличия от V Rising

- **Без PvP** — фокус на кооперативном PvE
- **Упор на слуг** — захват, прокачка и экипировка слуг как ключевая механика
- **Процедурная генерация мира** при старте сервера (аналог Valheim без деформации ландшафта)
- **Платформа Roblox** — доступность на всех устройствах, облачные серверы

### Формат

| Параметр | Значение |
|---|---|
| Платформа | Roblox |
| Жанр | Co-op Action RPG |
| Камера | Изометрическая (3/4 вид) с вращением и зумом |
| Игроки на сервер | 1–4 (кооператив) |
| Режим сервера | Private Server (облачный, персистентный) |
| Сохранение | DataStore: прогресс игрока + состояние мира |
| Целевая аудитория | 13+ |

## Сеттинг и атмосфера

Готическое тёмное фэнтези. Игрок — пробудившийся вампир в мире, населённом людьми, зверями и другими сверхъестественными существами. Мир живёт по циклу дня и ночи: днём вампир слабеет под солнцем (дебафф `sunlight_exposure`), ночью — в полной силе. Лунный цикл (новолуние → полнолуние → кровавая луна) влияет на силу игрока и врагов.

### Цикл дня и ночи

| Параметр | Значение |
|---|---|
| Полный цикл | 20 минут реального времени (1200 сек) |
| Рассвет | Час 12 → 13 |
| Закат | Час 18 → 19 |
| Лунный цикл | 5 часов реального времени |

### Фазы луны

| Фаза | Эффект на игрока | Эффект на врагов |
|---|---|---|
| Новолуние | — | — |
| Растущая | — | — |
| Полнолуние | +15% скорость | +10% HP |
| Убывающая | — | — |
| Кровавая луна | +20% физ/маг сила | +30% урон, +50% агро |

Кровавая луна — самое опасное и выгодное время: враги сильнее, но и игрок мощнее. Специальное красное освещение и туман.

## Основной игровой цикл

```
Исследование мира
        │
        ▼
Сражения с врагами ──→ Лут и ресурсы
        │                       │
        ▼                       ▼
Захват слуг              Крафт экипировки
        │                       │
        ▼                       ▼
Охота на боссов ──→ Разблокировка технологий
        │                       │
        ▼                       ▼
Spell Points ──→ Изучение магии
        │
        ▼
Строительство замка
        │
        ▼
Генерация нового мира → повторение
```

### Прогрессия

1. **Ранняя игра (Lv 1–5)**: базовое оружие, охота на волков и воинов, первый слуга, сбор ресурсов
2. **Середина (Lv 6–12)**: первые боссы, разблокировка крафта и магии, экипировка слуг
3. **Поздняя игра (Lv 13–20)**: продвинутые боссы, ультимативные заклинания, полная прокачка

## Боевая система

### Оружие

Три типа оружия: Меч (ближний бой, комбо), Топор (ближний бой, медленный/сильный), Лук (дальний бой, каст + выстрел). Каждое оружие имеет 2 способности (Q и E) с кулдаунами.

| Оружие | Тип | Комбо | Q | E |
|---|---|---|---|---|
| Меч | Melee | 3 удара | Направленный удар | AoE замедление |
| Топор | Melee | 2 удара | AoE урон + бафф | Серия снарядов |
| Лук | Ranged | 1 выстрел | Усиленный выстрел | Дождь стрел |

### Формула урона

```
baseDamage × (1 + power/10) → крит (шанс × множитель) → сопротивление → модификатор уровней → финальный урон
```

Модификатор уровней: +1% за каждый уровень выше цели, −4% за каждый уровень ниже (cap ±100%).

### Магия

Две школы магии: **Blood** (Кровь) и **Chaos** (Хаос).

| Школа | Пассивка | Стиль |
|---|---|---|
| Blood | **Leech** — вампиризм, хил при ударах и убийствах | Контроль, поддержка, самолечение |
| Chaos | **Ignite** — поджог, DoT, взрывы при смерти | Агрессия, AoE урон, цепные реакции |

Заклинания имеют тиры I–III + Ultimate. Spell Points получаются с боссов. Экипировка: R (Basic), G (Basic), Z (Ultimate). Завершение полного тира даёт пассивный бонус школы.

Типы эффектов заклинаний:
- Projectile (одиночный снаряд)
- MultiProjectile (веер снарядов)
- AoEDamage (урон в области)
- AoEHeal (лечение в области)
- AoEBuff / AoEApplyPassive
- Beam (непрерывный луч)
- ChannelledProjectile (канализируемый поток)
- TargetAreaProjectile (снаряд в точку)
- HealCaster (самолечение)
- Block / FrontalBlock (щит)
- Immaterial (неуязвимость)
- Pull (притяжение)

### Снаряды

До 50 активных снарядов одновременно. Поддержка: гравитация, пробивание, радиус попадания, время жизни.

## Система крови

Вампир питается кровью поверженных врагов (клавиша F). Тип крови определяется типом врага. Кровь постепенно расходуется.

| Тип крови | Тир I | Тир II | MAX (100%) |
|---|---|---|---|
| Outcast (Изгой) | — | — | — |
| Warrior (Воин) | +10–20% физ. сила | +10–20% CD оружия | +20% все бонусы |
| Creature (Зверь) | +10–20% скорость | +12–24% лечение | +20% все бонусы |

Качество крови (1–100%) зависит от врага. Чем выше качество — тем сильнее бонусы.

## Слуги

Ключевая механика: захват врагов и превращение их в слуг.

### Захват

- Обычные враги: понизить HP до порога → Захватить (T)
- Боссы: убить босса N раз (эссенция) → при следующем downed → Захватить (T)

### Управление

| Режим | Описание |
|---|---|
| Aggressive | Атакует ближайшего врага |
| Defensive | Атакует только обидчиков хозяина |
| Passive | Не атакует |

| Команда | Описание |
|---|---|
| Follow | Следует за хозяином |
| Stay | Остаётся на месте |
| AttackTarget | Атакует указанную цель |

### Прокачка

Слуги получают XP зеркально игроку. У слуг есть свои слоты экипировки. Сила слуги масштабируется статом `FamiliarDamage` хозяина.

## Прогрессия персонажа

### Уровни

| Параметр | Значение |
|---|---|
| Макс. уровень | 20 |
| Базовое HP | 100 |
| HP за уровень | +20 |
| XP до следующего | BaseXP (100) × уровень |
| Источники XP | Убийство врагов |

### Статы (20 штук)

**Offensive**: MaxHP, PhysicalPower, MagicalPower, AttackSpeed, PhysCritChance, PhysCritDamage, MagicCritChance, MagicCritDamage, FamiliarDamage, WeaponCDSpeed, MagicCDSpeed

**Defensive**: PhysResistance, MagicResistance, HealthRegen, HealingReceived

**Utility**: MoveSpeed, BloodDrainRate, BloodBonusPower, ResourceDamage, ResourceYield

Статы складываются из: базовые + экипировка + кровь + тиры магии + баффы.

### Баффы и дебаффы

Временные модификаторы от способностей, зелий, крови, лунных фаз и солнечного света. Визуализация в BuffBar (зелёный — бафф, красный — дебафф).

## Инвентарь и крафт

### Инвентарь

- 24 слота по умолчанию (3×8), до 40 с сумкой (5×8)
- Слоты 1–8 = ActionBar (оружие, зелья)
- Экипировка: 10 слотов (Head, Chest, Legs, Feet, Hands, Cloak, Amulet, Ring1, Ring2, Bag)
- Drag-and-drop, стакинг, контекстное меню

### Типы предметов

| Тип | Стакается | Примеры |
|---|---|---|
| Weapon | Нет | Sword of Light, Iron Axe, Hunting Bow |
| Armor | Нет | Hide Helmet/Chest/Legs/Boots/Gloves |
| Accessory | Нет | Cloak, Amulet, Ring |
| Consumable | Да | Health Potion, Blood Vial, Servant Egg |
| Resource | Да | Wood, Stone, Rugged Hide, Blood Essence, Wooden Plank, Stone Brick, Sawdust |
| Bag | Нет | Small Bag (+1 ряд инвентаря) |

### Крафт

Рецепты разблокируются через убийства боссов (технологии). Крафт требует материалы и время. Всё серверно-авторитетно.

## Враги и боссы

### Текущие типы врагов

| Тип | Уровень | HP | Агро | Особенности |
|---|---|---|---|---|
| Warrior | 5 | 120 | 25 | Кровь Warrior, базовый враг |
| Wolf | 3–5 | 90 | 20 | Стайное агро (PackRadius=30), быстрый |
| TrainingDummy | 1 | 99999 | 0 | Тренировочный, не атакует |

*Планируется до 100 типов врагов.*

### Текущие боссы

| Босс | Уровень | Акт | HP | Способности | Разблокировки |
|---|---|---|---|---|---|
| Кровавый Воин | 6 | 1 | 10 | Blood Slash, Blood Nova, Blood Rage | Кровавая ковка, Blood Rage (Spell) |
| Глава лесопилки | 14 | 1 | 80 | Heavy Chop, Timber Fall | Обработка древесины, Chaos Volley |

*Планируется 20+ боссов.*

### Жизненный цикл босса

```
ALIVE → (HP=1) → DOWNED → (F: добить / T: захватить / timeout) → DEAD → респавн
```

Первое убийство босса даёт Spell Points и разблокирует технологии.

## Строительство замка (v1.9 ✅)

Система строительства в стиле V Rising. Серверно-авторитетная, с персистентностью в DataStore.

### Castle Heart

Центр замка. Определяет территорию (Claim) и лимиты. 3 уровня:

| Уровень | HP | Max блоков | Радиус | Max гробов | Стоимость апгрейда |
|---|---|---|---|---|---|
| 1 | 1000 | 200 | 48 studs | 1 | — |
| 2 | 2000 | 350 | 56 studs | 2 | 100 Blood Essence |
| 3 | 3000 | 500 | 64 studs | 3 | 250 Blood Essence |

### Типы блоков

- **Фундамент**: stone_foundation, wooden_foundation, basement_stairs
- **Стены**: stone_wall, wooden_wall, stone_wall_doorway, wooden_wall_doorway
- **Функциональные**: door, chest, sawmill, crusher, workbench, coffin

### Функциональные блоки

| Блок | Функция |
|---|---|
| Дверь | Открытие/закрытие (F), TweenService поворот 90° |
| Сундук | Хранилище, drag-and-drop, дроп при разрушении |
| Верстак | Крафт-станция (9 слотов), рецепты из CraftConfig |
| Лесопилка | Автокрафт: wood → plank, blood_plank |
| Дробилка | Автокрафт: stone → stone_brick |
| Гроб | Точка респавна, привязка по 1 на игрока |

### Разбор блоков (Dismantle)

ПКМ зажатие 1 сек → 100% возврат ресурсов. Нельзя разобрать блок с предметами внутри.

### Укрытие от солнца

Фундамент над головой = укрытие. `DayNightManager.isInShelter()` использует raycast вниз (фундамент/Castle Heart) + raycast к солнцу.

## Мир (Planned: v1.10)

### Процедурная генерация

Мир генерируется при создании сервера из seed. Terrain API (Perlin noise) для ландшафта, Part-based структуры клонируются из шаблонов (ServerStorage/Templates). Seed сохраняется в DataStore для воспроизводимости.

Три режима работы (`WorldConfig.Mode`):
- **Manual** — ручная сцена Studio (дефолт, для разработки)
- **Hybrid** — сгенерированный terrain + ручные объекты
- **Generated** — полная генерация из seed

### Биомы (planned)

- Тёмный лес (стартовая зона, Lv 1–6)
- Кровавый лес (средний уровень, Lv 5–12)
- Руины (боссы, Lv 5–18)
- Болото (поздняя игра)

## Персистентность

### Что сохраняется (DataStore)

| Данные | Механизм |
|---|---|
| Уровень и XP | LevelManager → DataService |
| Инвентарь и экипировка | InventoryManager → DataService |
| Кровь (тип, качество, количество) | BloodManager → DataService |
| Прогресс боссов (эссенция, техники) | BossManager → DataService |
| Слуги (захваченные, экипировка) | ServantManager → DataService |
| Магия (очки, изученные, экипированные) | SpellProgressManager → DataService |
| Мир (seed, постройки, прогресс боссов) | WorldSaveManager (planned) |

### Автосохранение

- Каждые 120 секунд
- При выходе игрока
- При выключении сервера (BindToClose, до 25 сек)
- UpdateAsync с version guard (защита от перезаписи)

### Хостинг

Roblox облачный сервер (Private Server). Сервер живёт пока хотя бы один игрок онлайн. При возвращении игроков мир восстанавливается из DataStore: seed → генерация ландшафта → загрузка построек → загрузка прогресса → спавн врагов.
